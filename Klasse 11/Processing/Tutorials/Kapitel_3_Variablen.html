Was lernst du in diesem Kapitel?

In Kapitel 2 hast du bereits Variablen wie mouseX und mouseY verwendet. Jetzt legst du eigene Variablen an und steuerst damit Positionen, Größen, Farben und Bewegungen.

Vorwissen: Du solltest Formen und Farben aus Kapitel 1 sowie setup(), draw() und Ereignisfunktionen aus Kapitel 2 kennen.
3.1

Variablen verstehen

3.1.1 Das Grundprinzip

Eine Variable ist ein benannter Speicherplatz. Dort kann ein Programm einen Wert ablegen und später wieder verwenden. Der gespeicherte Wert darf sich während des Programmlaufs ändern.

Datentypint
NamekreisX
Wert120

Die vollständige Zeile int kreisX = 120; bedeutet: Lege eine Variable für ganze Zahlen an, nenne sie kreisX und speichere darin den Wert 120.

Merke: Jede Variable besitzt mindestens einen Datentyp und einen Namen. Sobald ihr ein Wert zugewiesen wurde, besitzt sie zusätzlich einen aktuellen Inhalt.

3.1.2 Eine Variable deklarieren

Bevor eine eigene Variable verwendet werden kann, muss sie angelegt werden. Dieser Schritt heißt Deklaration.

Deklaration
int kreisX;          // Variable für eine ganze Zahl
float geschwindigkeit; // Variable für eine Kommazahl

Das allgemeine Muster lautet:

Allgemeiner Aufbau
DATENTYP variablenName;

Durch die Deklaration weiß Processing, wie die Variable heißt und welche Art von Wert dort gespeichert werden darf.

3.1.3 Einen Wert zuweisen und initialisieren

Mit einer Zuweisung wird ein Wert in einer Variablen gespeichert. Links steht immer die Variable, rechts der neue Wert oder eine Rechnung.

Zuweisungen
kreisX = 120;                // einfacher Wert
geschwindigkeit = 1.5;     // Kommazahl mit Punkt
kreisX = 50 + 20 * 2;      // zuerst rechnen, dann speichern
Das Gleichheitszeichen ist hier kein Vergleich: kreisX = 120; bedeutet nicht „kreisX ist gleich 120“, sondern „Speichere 120 in kreisX“.

Deklaration und erste Zuweisung können in einer Zeile stehen. Diese erste Wertvergabe nennt man Initialisierung.

Deklaration und Initialisierung
int kreisX = 120;
float geschwindigkeit = 1.5;

3.1.4 Eine Variable verwenden

Steht ein Variablenname in einem Befehl, setzt Processing an dieser Stelle den aktuellen Wert der Variable ein. Dies nennt man auch Substitution.

Variablen steuern eine Zeichnung
int kreisX = 120;
int kreisY = 150;
int durchmesser = 80;

void setup() {
  size(500, 300);
}

void draw() {
  background(235);
  fill(35, 145, 210);
  ellipse(kreisX, kreisY, durchmesser, durchmesser);
}

Beim Ausführen der Ellipse setzt Processing beispielsweise 120 für kreisX und 80 für durchmesser ein. Ändert sich später ein Wert, verwendet der nächste Durchlauf automatisch den neuen Wert.

3.1.5 Erlaubte und sinnvolle Variablennamen

Ein guter Name verrät, wofür eine Variable verwendet wird. ballGeschwindigkeit ist deshalb hilfreicher als bg.

RegelBeispiel
mit einem Kleinbuchstaben beginnenkreisX
keine Leerzeichen oder Bindestriche verwendenballGroesse
nicht mit einer Ziffer beginnenspieler2, nicht 2spieler
keine reservierten Wörter wie int verwendenanzahl
Groß- und Kleinschreibung beachtenkreisX ist nicht kreisx
Umlaute und ß im Code vermeidengroesse statt größe
mehrere Wörter in lowerCamelCase verbindenhintergrundFarbe
Konvention: Namen wie kreisX oder maximaleGeschwindigkeit sind nicht nur erlaubt, sondern auch gut lesbar. Unterstriche und Dollarzeichen wären teilweise möglich, werden in unserem Kurs aber nicht benötigt.
3.2

Datentypen

3.2.1 Ganze Zahlen und Kommazahlen

Der Datentyp legt fest, welche Werte in einer Variablen gespeichert werden dürfen. Für unsere Programme sind zunächst zwei Zahlentypen besonders wichtig:

DatentypGeeignet fürBeispiele
intganze Zahlen ohne Nachkommastellen-3, 0, 250
floatZahlen mit Nachkommastellen1.5, -0.25, 80.0
int und float
int anzahlKreise = 4;
float tempo = 1.5;
float mitte = 75.0 / 2;
Kommazahlen mit Punkt: Schreibe im Programm 1.5 und nicht 1,5. Das Komma trennt in Processing die Parameter eines Befehls.
Weitere Zahlentypen: Es gibt unter anderem byte, short, long und double. Für unsere aktuellen Processing-Programme genügen meistens int und float.

3.2.2 Wahrheitswerte und einzelne Zeichen

DatentypBedeutungBeispiel
booleanWahrheitswert: wahr oder falschboolean lichtAn = true;
chargenau ein Zeichenchar taste = 'a';
boolean und char ausgeben
boolean programmLaeuft = true;
char startTaste = 's';

println(programmLaeuft);
println(startTaste);

Ein char steht in einfachen Anführungszeichen. Wahrheitswerte werden im nächsten Kapitel besonders wichtig, wenn Bedingungen hinzukommen.

3.2.3 Text mit String

Ein String speichert eine Zeichenkette, also Text. Der Typ beginnt mit einem Großbuchstaben und der Text steht in doppelten Anführungszeichen.

Text speichern und verbinden
String objektName = "Ball";
int positionX = 120;

println(objektName + " steht bei x = " + positionX);

Das Pluszeichen verbindet hier Textstücke und Variablenwerte. Die Konsole zeigt:

Ausgabe
Ball steht bei x = 120

Das Verbinden von Zeichenketten nennt man String-Konkatenation.

3.2.4 Datentypen umwandeln

Manchmal besitzt ein Wert nicht den benötigten Datentyp. Mit int() und float() kann ein Zahlenwert gezielt umgewandelt werden.

Zahlen umwandeln
float zufallsWert = random(100); // zum Beispiel 63.84
int ganzeZahl = int(zufallsWert); // daraus wird 63

int anzahl = 5;
float haelfte = float(anzahl) / 2; // ergibt 2.5

int() schneidet den Nachkommaanteil ab; es wird nicht automatisch auf die nächste ganze Zahl gerundet.

3.3

Variablenwerte verarbeiten und verändern

3.3.1 So wird eine Zuweisung verarbeitet

Bei einer Zuweisung arbeitet Processing immer in derselben Reihenfolge: Zuerst werden die Variablen auf der rechten Seite durch ihre aktuellen Werte ersetzt. Danach wird gerechnet. Erst zuletzt wird das Ergebnis links gespeichert.

Beispiel
int a = 5;
int b = 0;

b = a + 10;
Variablenwert einsetzen: Aus b = a + 10; wird b = 5 + 10;.
Rechnung ausführen: Aus b = 5 + 10; wird b = 15;.
Ergebnis speichern: Die Variable b erhält den neuen Wert 15.

Bei längeren Rechnungen gelten die bekannten Regeln: Klammern sowie Punktrechnung werden vor Strichrechnung verarbeitet.

3.3.2 Einen vorhandenen Wert verändern

Damit eine Variable beispielsweise um 1 wächst, muss der berechnete neue Wert wieder in derselben Variable gespeichert werden.

Wert erhöhen
int x = 10;
x = x + 1;  // x erhält den neuen Wert 11
Keine Veränderung
x + 1; berechnet zwar einen Wert, speichert ihn aber nirgends.
Wert verändert
x = x + 1; berechnet den neuen Wert und weist ihn wieder x zu.
Kurzschreibweise: x++; erhöht x ebenfalls um 1. Für den Anfang ist x = x + 1; oft verständlicher, weil die Zuweisung sichtbar bleibt.

3.3.3 Ausführungsreihenfolge im aktiven Modus

Globale Variablen ergänzen den bekannten Ablauf aus Kapitel 2. Processing verarbeitet ein aktives Programm in dieser Reihenfolge:

1. Globale Variablenanlegen und initialisieren
→
2. setup()einmal ausführen
→
3. draw()immer wieder ausführen
Werte Schritt für Schritt verfolgen
int punktestand = 0; // zuerst: globale Initialisierung

void setup() {
  println(punktestand); // Ausgabe: 0
  punktestand = punktestand + 1;
}

void draw() {
  println(punktestand); // 1, danach 101, 201, ...
  punktestand = punktestand + 100;
}
Merke: Eine globale Initialisierung geschieht nur einmal beim Programmstart. Eine Zuweisung in draw() wird dagegen in jedem Frame erneut ausgeführt.

3.3.4 Animation mit einer Variablen

Eine Animation entsteht, wenn draw() ein Objekt zeichnet und anschließend eine seiner Eigenschaften verändert. Im nächsten Frame wird das Objekt mit dem neuen Wert gezeichnet.

Ein Ball bewegt sich nach rechts
float ballX = 0;
float tempo = 1.5;

void setup() {
  size(500, 300);
}

void draw() {
  background(235);           // altes Bild löschen
  fill(240, 100, 60);
  ellipse(ballX, 150, 50, 50);
  ballX = ballX + tempo;       // Position für den nächsten Frame
}
ballX
speichert die aktuelle x-Koordinate des Balls.
tempo
legt fest, um wie viele Pixel sich die Position pro Frame verändert.

Die häufig benötigte Geschwindigkeit steht nur an einer Stelle. Wird tempo auf 4 gesetzt, bewegt sich der Ball schneller.

3.3.5 Variablen durch Events verändern

Ereignisfunktionen können Variablen verändern. draw() verwendet danach in allen folgenden Frames die neuen Werte.

Tastatur und Maus ändern den Hintergrund
int rot = 230;
int gruen = 230;
int blau = 230;

void setup() {
  size(500, 300);
}

void draw() {
  background(rot, gruen, blau); // aktuelle Werte verwenden
  fill(255);
  rect(190, 100, 120, 100);
}

void keyPressed() {
  rot = 210; gruen = 50; blau = 50; // rot
}

void mousePressed() {
  rot = 45; gruen = 170; blau = 90; // grün
}

Die Ereignisfunktionen zeichnen hier nichts. Sie verändern nur Daten. Die gesamte Darstellung bleibt in draw() und wird dort mit den jeweils aktuellen Farbwerten aufgebaut.

3.4

Globale und lokale Variablen

3.4.1 Globale Variablen

Eine globale Variable wird außerhalb von setup(), draw() und den Ereignisfunktionen deklariert – üblicherweise ganz oben im Programm. Sie kann in allen Code-Blöcken verwendet und verändert werden.

Eine Variable in mehreren Code-Blöcken
float ballX = 0; // global: überall sichtbar

void setup() {
  size(500, 300);
}

void draw() {
  background(245);
  ellipse(ballX, 150, 50, 50);
  ballX = ballX + 2;
}

void keyPressed() {
  ballX = 0; // Ball zurücksetzen
}

ballX muss global sein, weil draw() und keyPressed() auf denselben gespeicherten Wert zugreifen.

3.4.2 Lokale Variablen

Eine lokale Variable wird innerhalb eines Code-Blocks deklariert. Sie ist nur dort verfügbar und eignet sich für Zwischenergebnisse, die außerhalb dieses Blocks nicht benötigt werden.

Lokales Zwischenergebnis in draw()
float ballX = 20; // global

void setup() {
  size(500, 300);
}

void draw() {
  background(235);
  float durchmesser = ballX / 2 + 20; // lokal
  ellipse(ballX, 150, durchmesser, durchmesser);
  ballX = ballX + 1;
}

durchmesser wird nur für die Zeichnung in draw() benötigt. Nach jedem Durchlauf endet seine Gültigkeit; im nächsten Frame wird die lokale Variable neu angelegt und neu berechnet.

3.4.3 Skopus: Wo gilt eine Variable?

Der Skopus – englisch scope – ist der Bereich, in dem eine Variable sichtbar und verwendbar ist.

VariableDeklarationSkopus
globalaußerhalb aller Code-Blöckegesamtes Programm
lokalinnerhalb eines Code-Blocksvon der Deklaration bis zur schließenden Klammer des Blocks
Außerhalb des Skopus
void setup() {
  int startX = 50; // nur in setup() bekannt
}

void draw() {
  ellipse(startX, 100, 40, 40);
  // Fehler: startX ist hier unbekannt
}

Soll startX sowohl in setup() als auch in draw() benutzt werden, muss die Variable global deklariert werden.

3.4.4 Überschatten vermeiden

Wird innerhalb eines Blocks eine neue lokale Variable mit demselben Namen wie eine globale Variable deklariert, verdeckt die lokale Variable vorübergehend die globale. Dies nennt man Überschatten.

Fehler durch Überschatten
float ballX = 0; // globale Variable

void setup() {
  size(500, 300);
  float ballX = 100; // neue lokale Variable!
}

void draw() {
  ellipse(ballX, 150, 40, 40);
  // Verwendet weiterhin das globale ballX mit dem Wert 0
}

In setup() wurde versehentlich ein zweites ballX angelegt. Die globale Variable bleibt unverändert. Richtig ist eine normale Zuweisung ohne erneuten Datentyp:

Korrektur
void setup() {
  size(500, 300);
  ballX = 100; // vorhandene globale Variable verändern
}
Merke: Der Datentyp steht nur dort, wo eine neue Variable deklariert wird. Bei einer späteren Zuweisung wird nur der Variablenname geschrieben.
3.5

Typische Fehler

Die Variable wurde nicht deklariert

Bevor du tempo verwendest, muss eine passende Deklaration wie float tempo = 2.5; vorhanden sein.

Der Datentyp passt nicht zum Wert

int tempo = 1.5; funktioniert nicht, weil int keine Nachkommastellen speichert. Verwende float.

Eine Kommazahl wurde mit Komma geschrieben

Schreibe 1.5 statt 1,5. Das Dezimaltrennzeichen im Programmcode ist der Punkt.

Der Wert wird berechnet, aber nicht gespeichert

x + 1; verändert x nicht. Benötigt wird die Zuweisung x = x + 1;.

Eine lokale Variable wird außerhalb ihres Blocks verwendet

Prüfe die geschweiften Klammern. Eine in setup() deklarierte lokale Variable ist in draw() nicht sichtbar.

Eine globale Variable wird versehentlich überschattet

Schreibe bei einer späteren Zuweisung nicht erneut den Datentyp. ballX = 100; verändert die vorhandene Variable; float ballX = 100; legt eine neue lokale Variable an.

Groß- und Kleinschreibung wurden vertauscht

kreisX, KreisX und kreisx sind drei verschiedene Namen. Verwende einen Namen im gesamten Programm einheitlich.
