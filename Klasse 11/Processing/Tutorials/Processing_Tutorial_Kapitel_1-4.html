1.1

Grundformen zeichnen

Pixel, Koordinaten, Befehle und Zeichenreihenfolge

1.1.1 Der Bildschirm besteht aus Pixeln

Ein digitales Bild setzt sich aus vielen kleinen Bildpunkten zusammen. Diese Bildpunkte heißen Pixel. Damit Processing jeden Ort im Zeichenfenster eindeutig findet, besitzt jeder Punkt zwei Koordinaten:

  • x beschreibt die Position von links nach rechts.
  • y beschreibt die Position von oben nach unten.
Das Koordinatensystem in Processing

Anders als im Mathematikunterricht liegt der Ursprung links oben. Die y-Werte werden nach unten größer.

!

Bei 600 × 400 Pixeln: Die sichtbaren x-Positionen reichen von 0 bis 599, die y-Positionen von 0 bis 399. Die Zählung beginnt bei 0.

1.1.2 Anweisungen und Programme

Eine Anweisung ist ein präziser Befehl an den Computer. Ein Programm ist eine geordnete Folge solcher Anweisungen. Processing arbeitet den Code von oben nach unten ab.

Aufbau einer Anweisung
point(120, 80);
point

Name des Befehls: Processing soll einen Punkt zeichnen.

(120, 80)

Parameter: Sie legen die x- und y-Position des Punktes fest.

;

Semikolon: Es beendet die Anweisung.

1.1.3 Die wichtigsten Grundformen

Punkt

point(x, y);

Ein einzelner Punkt an der Position (x, y).

Linie

line(x1, y1, x2, y2);

Verbindet einen Startpunkt mit einem Endpunkt.

Dreieck

triangle(x1, y1, x2, y2, x3, y3);

Die drei Punktpaare bestimmen die drei Ecken.

Rechteck

rect(x, y, breite, hoehe);

Normalerweise: linke obere Ecke, dann Breite und Höhe.

Kreis

circle(x, y, durchmesser);

Mittelpunkt und Durchmesser bestimmen den Kreis.

Ellipse

ellipse(x, y, breite, hoehe);

Mittelpunkt, waagerechter und senkrechter Durchmesser.

Beispiel: mehrere Grundformen
size(500, 300);
        background(245);

        point(40, 40);
        line(70, 40, 190, 90);
        triangle(230, 100, 300, 100, 265, 35);
        rect(50, 150, 130, 80);
        circle(270, 190, 90);
        ellipse(410, 190, 120, 70);

1.1.4 Die Zeichenreihenfolge entscheidet

Processing zeichnet wie auf Papier: Was später gezeichnet wird, liegt weiter vorn und kann frühere Formen verdecken.

Beispiel: Haus aus Grundformen
size(360, 300);
        background(235);

        // Zuerst der Hauskörper
        rect(90, 120, 180, 130);

        // Das Dach wird danach davor gezeichnet
        triangle(70, 120, 290, 120, 180, 40);

        // Tür und Fenster liegen ganz vorn
        rect(155, 180, 50, 70);
        rect(110, 150, 30, 30);
        rect(220, 150, 30, 30);
M

Merksatz: Processing arbeitet von oben nach unten. Die zuletzt gezeichnete Form liegt ganz vorn.

1.2

Weitere Formen

Ellipsensegmente und frei zusammengesetzte Vielecke

1.2.1 Teile einer Ellipse mit arc()

Mit arc() wird nur ein Ausschnitt einer Ellipse gezeichnet. Zu Mittelpunkt, Breite und Höhe kommen ein Start- und ein Endwinkel hinzu.

Allgemeiner Aufbau

arc(x, y, breite, hoehe, startwinkel, endwinkel);

Der Winkel 0° zeigt vom Mittelpunkt nach rechts. Wegen der nach unten laufenden y-Achse werden die Winkel auf dem Bildschirm im Uhrzeigersinn sichtbar.

Winkel bei arc()

Gezeigt ist ein Bogen von 30° bis 330°. Start- und Endpunkt sind rot markiert.

Processing rechnet intern mit dem Bogenmaß. Für den Einstieg ist radians() besonders lesbar: Die Funktion wandelt Grad in Bogenmaß um.

Beispiel: Ellipsensegment
size(300, 220);
        background(245);

        arc(150, 110, 180, 120,
            radians(30), radians(330));

Alternativ entspricht ein Vollkreis 2 * PI. So lässt sich 30° auch als PI / 6 angeben.

1.2.2 Beliebige Vielecke mit beginShape()

Ein Polygon ist ein Vieleck. Processing verbindet dazu mehrere selbst festgelegte Eckpunkte. Jeder Eckpunkt wird mit vertex(x, y) angegeben.

Beispiel: ein unregelmäßiges Fünfeck
size(320, 260);
        background(245);

        beginShape();
        vertex(160, 30);  // 1. Ecke
        vertex(270, 100); // 2. Ecke
        vertex(225, 220); // 3. Ecke
        vertex(85, 210);  // 4. Ecke
        vertex(45, 90);   // 5. Ecke
        endShape(CLOSE);
BefehlAufgabe
beginShape();Startet die Beschreibung einer neuen Form.
vertex(x, y);Fügt einen Eckpunkt hinzu. Die Reihenfolge bestimmt die Verbindungslinien.
endShape(CLOSE);Beendet und schließt die Form: Der letzte Punkt wird mit dem ersten verbunden.
endShape();Beendet die Form, ohne die letzte Verbindung automatisch zu zeichnen.
M

Merksatz: beginShape() öffnet die Form, vertex() setzt ihre Ecken und endShape(CLOSE) schließt sie.

1.3

Kontur, Füllung und Farben

Graustufen, RGB-Farben und Transparenz

1.3.1 Graustufen von 0 bis 255

Eine einzelne Zahl beschreibt eine Graustufe. 0 bedeutet schwarz, 255 bedeutet weiß. Werte dazwischen ergeben verschiedene Grautöne. Als Merkhilfe kannst du dir die Zahl als Lichtmenge vorstellen.

Graustufen

1.3.2 Füllung und Kontur

fill() legt die Farbe im Inneren einer Form fest. stroke() legt die Konturfarbe fest, strokeWeight() ihre Dicke in Pixeln.

fill(80);

Die folgenden Flächen werden dunkelgrau gefüllt.

stroke(255);

Die folgenden Konturen werden weiß.

strokeWeight(5);

Die folgenden Konturen werden 5 Pixel dick.

noFill();

Die folgenden Formen erhalten keine Füllung.

noStroke();

Die folgenden Formen erhalten keine Kontur.

!

Die Gestaltung bleibt aktiv: Ein Farbbefehl gilt für alle Formen, die danach gezeichnet werden – bis ein neuer Farbbefehl ihn ersetzt.

Beispiel: Stile nacheinander verändern
size(520, 220);
        background(235);

        fill(60);          // dunkelgraue Füllung
        stroke(255);       // weiße Kontur
        strokeWeight(5);
        circle(100, 110, 120);

        noStroke();        // Kontur ab jetzt aus
        fill(150);
        rect(210, 50, 110, 120);

        noFill();          // Füllung ab jetzt aus
        stroke(0);         // Kontur wieder an
        strokeWeight(3);
        triangle(385, 170, 465, 170, 425, 45);

1.3.3 Größe und Hintergrund des Zeichenfensters

size(breite, hoehe) bestimmt die Größe des Fensters. background() füllt das gesamte Fenster mit einer Farbe und übermalt dabei alles, was bereits zu sehen war.

Die ersten Zeilen eines einfachen Programms
size(600, 400);  // 600 Pixel breit, 400 Pixel hoch
        background(245); // fast weißer Hintergrund

        circle(300, 200, 140);
×

background() nicht ans Ende setzen: Dann wird die gesamte vorherige Zeichnung übermalt. In einfachen Programmen steht der Hintergrund vor den Formen.

1.3.4 RGB-Farben

Farben entstehen aus drei Anteilen: Rot, Grün und Blau. Jeder Anteil kann einen Wert von 0 bis 255 besitzen. Die Reihenfolge ist immer R – G – B.

255, 0, 0
0, 255, 0
0, 0, 255
128, 60, 210
BefehlWirkung
fill(255, 0, 0);rote Füllung
stroke(0, 0, 255);blaue Kontur
background(240, 245, 255);sehr heller, leicht blauer Hintergrund
fill(255, 255, 0);Gelb durch Rot + Grün

1.3.5 Transparenz mit dem Alpha-Wert

Ein zusätzlicher Wert steuert die Deckkraft. Dieser Alpha-Wert reicht ebenfalls von 0 bis 255:

  • 255: vollständig deckend
  • 0: vollständig durchsichtig
  • Werte dazwischen: teilweise transparent
Beispiel: überlagerte, transparente Kreise
size(420, 260);
        background(245);
        noStroke();

        fill(255, 0, 0, 150);  // Rot + Alpha
        circle(160, 130, 150);

        fill(0, 90, 255, 150); // Blau + Alpha
        circle(255, 130, 150);

Bei einer Graustufe besteht die Kurzform aus zwei Werten: fill(grauwert, alpha). Bei einer RGB-Farbe sind es vier Werte: fill(rot, gruen, blau, alpha).

1.3.6 Ein vollständiges Farb-Beispiel

Beispiel: farbige Landschaft
size(600, 360);
        background(180, 225, 255); // Himmel

        noStroke();
        fill(255, 205, 55);       // Sonne
        circle(500, 80, 90);

        fill(65, 155, 90);        // Wiese
        rect(0, 240, 600, 120);

        fill(215, 80, 65);        // Haus
        rect(180, 170, 170, 120);

        fill(70, 75, 95);         // Dach
        triangle(155, 170, 375, 170, 265, 85);

        stroke(255);                   // Fenster
        strokeWeight(4);
        fill(120, 210, 245);
        rect(215, 205, 45, 45);
M

Merksatz: Erst Stil festlegen, dann Form zeichnen. fill(), stroke() und strokeWeight() wirken immer auf die danach folgenden Formen.

1.4 Typische Fehler - schnell erkannt

Die Form sitzt zu tief.

Der y-Wert wächst nach unten, nicht nach oben.

Processing meldet einen Syntaxfehler.

Prüfe Semikolon, Klammern, Kommata und die Schreibweise des Befehls.

Breite und Position wirken vertauscht.

Vergleiche Anzahl und Reihenfolge der Parameter mit der Befehlstabelle.

Alle Formen haben dieselbe Farbe.

Ein fill()-Befehl bleibt aktiv, bis ein neuer folgt.

Die Zeichnung ist verschwunden.

Ein später background()-Befehl hat sie wahrscheinlich übermalt.

Das Vieleck ist offen.

Verwende endShape(CLOSE), wenn letzter und erster Punkt verbunden werden sollen.

Ein Teil liegt hinter einer anderen Form.

Ändere die Reihenfolge der Zeichenbefehle.

1.5 Das Wichtigste auf einen Blick

  • Der Ursprung (0, 0) liegt links oben.
  • x wächst nach rechts, y wächst nach unten.
  • Parameter stehen in Klammern und werden durch Kommata getrennt.
  • Ein Semikolon beendet eine Anweisung.
  • Später gezeichnete Formen liegen weiter vorn.
  • arc() zeichnet einen Teil einer Ellipse.
  • Vielecke entstehen mit beginShape(), vertex() und endShape().
  • Graustufen reichen von 0 bis 255.
  • RGB-Farben bestehen aus Rot, Grün und Blau.
  • Der Alpha-Wert steuert die Deckkraft.
  • Gestaltungsbefehle gelten für alle nachfolgenden Formen.

Bisher hat Processing ein Bild gezeichnet und war danach fertig. Jetzt lernst du Programme kennen, die weiterlaufen und auf Eingaben reagieren.

2.1

Programmablauf: statisch und aktiv

2.1.1 Statischer Modus

Im statischen Modus arbeitet Processing die Befehle einmal von oben nach unten ab. Nach der letzten Zeile ist das Programm beendet. So waren die Programme aus Kapitel 1 aufgebaut.

Beispiel: ein fertiges Bild
size(400, 300);
        background(230);
        fill(40, 130, 210);
        ellipse(200, 150, 100, 100);

Jede Zeile wird genau einmal ausgeführt. Der Kreis kann sich danach nicht bewegen und das Programm kann noch nicht auf Eingaben reagieren.

2.1.2 Aktiver Modus mit setup() und draw()

Für Bewegung und Interaktion braucht Processing den aktiven Modus. Dabei übernehmen zwei besondere Bereiche unterschiedliche Aufgaben:

StartProgramm beginnt
→
setup()einmal ausführen
→
draw()immer wieder ausführen
Grundgerüst des aktiven Modus
void setup() {
          size(400, 300);  // Wird einmal ausgeführt
        }

        void draw() {
          background(230);  // Wird ständig wiederholt
          ellipse(mouseX, mouseY, 40, 40);
        }
setup()
Hier stehen Einstellungen, die nur am Anfang benötigt werden, zum Beispiel die Fenstergröße.
draw()
Dieser Code wird wieder und wieder ausgeführt, bis das Programm gestoppt wird.
Merke: Erst läuft setup() einmal. Danach läuft draw() in einer ständigen Wiederholung.

2.1.3 Code-Blöcke und geschweifte Klammern

Die geschweiften Klammern { und } schließen einen Code-Block ein. Sie zeigen Processing, welche Befehle zusammengehören.

Ein Code-Block
void setup() {          // Block beginnt
          size(400, 300);      // Gehört zu setup()
          strokeWeight(3);     // Gehört ebenfalls dazu
        }                       // Block endet

Die Befehle innerhalb eines Blocks werden eingerückt. Das verändert die Ausführung nicht, macht den Code aber deutlich leichter lesbar. Processing kann über Bearbeiten → Autoformatierung automatisch einrücken.

Nicht mischen: Sobald du setup() oder draw() verwendest, gehören alle ausführbaren Zeichenbefehle in einen passenden Code-Block.

2.1.4 Frame Rate

Ein einzelner Durchlauf von draw() heißt Frame. Processing versucht normalerweise, etwa 60 Frames pro Sekunde darzustellen. Diese Häufigkeit heißt Frame Rate.

Langsame Wiederholung sichtbar machen
void setup() {
          size(400, 300);
          frameRate(2);  // Höchstens zwei Frames pro Sekunde
        }

        void draw() {
          println("draw wird ausgeführt");
        }

Der Befehl frameRate(2) legt eine Obergrenze von zwei Durchläufen pro Sekunde fest. Für die meisten Programme musst du die voreingestellte Frame Rate nicht verändern.

2.2

Interaktion mit der Maus

2.2.1 Die aktuelle Mausposition

Processing stellt die aktuelle Position des Mauszeigers automatisch bereit:

BegriffBedeutung
mouseXaktuelle x-Koordinate der Maus
mouseYaktuelle y-Koordinate der Maus

Du kannst beide Wörter überall dort einsetzen, wo Processing eine Zahl erwartet. Ihr Wert ändert sich passend zur Mausposition.

Ein Kreis folgt der Maus
void setup() {
          size(500, 350);
        }

        void draw() {
          background(235);              // Altes Bild übermalen
          fill(30, 150, 210);
          ellipse(mouseX, mouseY, 50, 50); // Maus bestimmt die Position
        }
Noch kein Variablenkapitel: mouseX und mouseY sind Variablen, die Processing für dich verwaltet. Im Moment genügt es, ihre Bedeutung zu kennen.

2.2.2 Bewegung oder Spur?

Ob eine Form scheinbar bewegt wird oder eine Spur hinterlässt, hängt davon ab, ob der Hintergrund in jedem Frame neu gezeichnet wird.

background() in draw()
Das vorige Bild wird ständig übermalt. Man sieht nur die aktuelle Position.
Kein background() in draw()
Die alten Zeichnungen bleiben sichtbar. Es entsteht eine Spur.
Mit der Maus Punkte zeichnen
void setup() {
          size(500, 350);
          background(255);  // Nur einmal löschen
          strokeWeight(5);
        }

        void draw() {
          point(mouseX, mouseY); // Jeder Punkt bleibt erhalten
        }
Merke: Die Position von background() entscheidet mit darüber, ob frühere Zeichnungen verschwinden oder sichtbar bleiben.

2.2.3 Die vorherige Mausposition

Zwischen einzelnen Punkten können bei schnellen Mausbewegungen Lücken entstehen. Für eine geschlossene Linie verbindet man die vorige mit der aktuellen Mausposition.

BegriffBedeutung
pmouseXx-Koordinate der Maus im vorherigen Frame
pmouseYy-Koordinate der Maus im vorherigen Frame
Eine durchgehende Linie zeichnen
void setup() {
          size(500, 350);
          background(255);
          strokeWeight(3);
        }

        void draw() {
          line(pmouseX, pmouseY, mouseX, mouseY);
          // Linie von der vorherigen zur aktuellen Position
        }
2.3

Interaktion mit Tasten und Mausklicks

2.3.1 Auf einen Tastendruck reagieren

Der Code-Block von keyPressed() wird genau dann ausgeführt, wenn eine beliebige Taste der Tastatur gedrückt wird.

Tastendruck färbt den Hintergrund schwarz
void setup() {
          size(500, 350);
          background(220);
        }

        void draw() {
          // Bleibt leer, hält das Programm aber aktiv
        }

        void keyPressed() {
          background(0); // Wird bei einem Tastendruck ausgeführt
        }

Welche Taste gedrückt wurde, unterscheiden wir an dieser Stelle noch nicht. Dafür wären zusätzliche Abfragen nötig.

2.3.2 Auf einen Mausklick reagieren

Für einen Mausklick gibt es den passenden Code-Block mousePressed(). Er wird bei jedem Drücken einer Maustaste einmal ausgeführt.

Mausklick zeichnet einen Kreis
void setup() {
          size(500, 350);
          background(245);
          fill(240, 90, 70);
        }

        void draw() {
          // Kein background(): gezeichnete Kreise bleiben sichtbar
        }

        void mousePressed() {
          ellipse(mouseX, mouseY, 40, 40);
          // Ein Kreis an der angeklickten Position
        }

2.3.3 Zwei Arten der Interaktion

Die bisherigen Beispiele zeigen zwei verschiedene Arten, wie ein Programm auf die Nutzerin oder den Nutzer reagieren kann:

ArtWann reagiert das Programm?Beispiele
kontinuierlichfortlaufend in jedem FramemouseX, mouseY
punktuellgenau beim Eintreten eines EreignisseskeyPressed(), mousePressed()

Ein solches punktuelles Ereignis nennt man auch Event. Processing ruft den passenden Code-Block automatisch auf, sobald das Event eintritt.

2.4

Typische Fehler

Befehle stehen außerhalb der Code-Blöcke

Im aktiven Modus dürfen Zeichenbefehle nicht lose zwischen setup(), draw() und den Ereignisfunktionen stehen. Verschiebe sie in den passenden Block.

Eine geschweifte Klammer fehlt

Jede öffnende Klammer { benötigt eine schließende Klammer }. Nutze die Autoformatierung, um die Blockstruktur besser zu erkennen.

Die Zeichnung hinterlässt ungewollt eine Spur

Setze background() an den Anfang von draw(), wenn das vorige Bild in jedem Frame gelöscht werden soll.

Die Zeichnung verschwindet sofort wieder

Ein background() in draw() übermalt auch Formen, die bei einem Klick gezeichnet wurden. Entferne es dort, wenn die Formen sichtbar bleiben sollen.

Groß- und Kleinschreibung stimmen nicht

mouseX, mouseY, pmouseX, keyPressed() und mousePressed() müssen exakt geschrieben werden.

Ein Tastendruck oder Mausklick bewirkt nichts

Füge eine draw()-Funktion hinzu, damit das Programm aktiv bleibt. Sie darf leer sein.

2.5 Kurzfassung

Statischer ModusAlle Befehle laufen einmal von oben nach unten.
Aktiver Modussetup() läuft einmal, draw() immer wieder.
MauspositionmouseX und mouseY liefern die aktuellen Koordinaten.
Vorige PositionpmouseX und pmouseY gehören zum vorherigen Frame.
TastendruckDer Block keyPressed() läuft bei einem Tastendruck.

Variablen

Werte speichern, gezielt verändern und in mehreren Code-Blöcken verwenden.

Was lernst du in diesem Kapitel?

In Kapitel 2 hast du bereits Variablen wie mouseX und mouseY verwendet. Jetzt legst du eigene Variablen an und steuerst damit Positionen, Größen, Farben und Bewegungen.

Vorwissen: Du solltest Formen und Farben aus Kapitel 1 sowie setup(), draw() und Ereignisfunktionen aus Kapitel 2 kennen.
3.1

Variablen verstehen

3.1.1 Das Grundprinzip

Eine Variable ist ein benannter Speicherplatz. Dort kann ein Programm einen Wert ablegen und später wieder verwenden. Der gespeicherte Wert darf sich während des Programmlaufs ändern.

Datentypint
NamekreisX
Wert120

Die vollständige Zeile int kreisX = 120; bedeutet: Lege eine Variable für ganze Zahlen an, nenne sie kreisX und speichere darin den Wert 120.

Merke: Jede Variable besitzt mindestens einen Datentyp und einen Namen. Sobald ihr ein Wert zugewiesen wurde, besitzt sie zusätzlich einen aktuellen Inhalt.

3.1.2 Eine Variable deklarieren

Bevor eine eigene Variable verwendet werden kann, muss sie angelegt werden. Dieser Schritt heißt Deklaration.

Deklaration
int kreisX;          // Variable für eine ganze Zahl
        float geschwindigkeit; // Variable für eine Kommazahl

Das allgemeine Muster lautet:

Allgemeiner Aufbau
DATENTYP variablenName;

Durch die Deklaration weiß Processing, wie die Variable heißt und welche Art von Wert dort gespeichert werden darf.

3.1.3 Einen Wert zuweisen und initialisieren

Mit einer Zuweisung wird ein Wert in einer Variablen gespeichert. Links steht immer die Variable, rechts der neue Wert oder eine Rechnung.

Zuweisungen
kreisX = 120;                // einfacher Wert
        geschwindigkeit = 1.5;     // Kommazahl mit Punkt
        kreisX = 50 + 20 * 2;      // zuerst rechnen, dann speichern
Das Gleichheitszeichen ist hier kein Vergleich: kreisX = 120; bedeutet nicht „kreisX ist gleich 120“, sondern „Speichere 120 in kreisX“.

Deklaration und erste Zuweisung können in einer Zeile stehen. Diese erste Wertvergabe nennt man Initialisierung.

Deklaration und Initialisierung
int kreisX = 120;
        float geschwindigkeit = 1.5;

3.1.4 Eine Variable verwenden

Steht ein Variablenname in einem Befehl, setzt Processing an dieser Stelle den aktuellen Wert der Variable ein. Dies nennt man auch Substitution.

Variablen steuern eine Zeichnung
int kreisX = 120;
        int kreisY = 150;
        int durchmesser = 80;

        void setup() {
          size(500, 300);
        }

        void draw() {
          background(235);
          fill(35, 145, 210);
          ellipse(kreisX, kreisY, durchmesser, durchmesser);
        }

Beim Ausführen der Ellipse setzt Processing beispielsweise 120 für kreisX und 80 für durchmesser ein. Ändert sich später ein Wert, verwendet der nächste Durchlauf automatisch den neuen Wert.

3.1.5 Erlaubte und sinnvolle Variablennamen

Ein guter Name verrät, wofür eine Variable verwendet wird. ballGeschwindigkeit ist deshalb hilfreicher als bg.

RegelBeispiel
mit einem Kleinbuchstaben beginnenkreisX
keine Leerzeichen oder Bindestriche verwendenballGroesse
nicht mit einer Ziffer beginnenspieler2, nicht 2spieler
keine reservierten Wörter wie int verwendenanzahl
Groß- und Kleinschreibung beachtenkreisX ist nicht kreisx
Umlaute und ß im Code vermeidengroesse statt größe
mehrere Wörter in lowerCamelCase verbindenhintergrundFarbe
Konvention: Namen wie kreisX oder maximaleGeschwindigkeit sind nicht nur erlaubt, sondern auch gut lesbar. Unterstriche und Dollarzeichen wären teilweise möglich, werden in unserem Kurs aber nicht benötigt.
3.2

Datentypen

3.2.1 Ganze Zahlen und Kommazahlen

Der Datentyp legt fest, welche Werte in einer Variablen gespeichert werden dürfen. Für unsere Programme sind zunächst zwei Zahlentypen besonders wichtig:

DatentypGeeignet fürBeispiele
intganze Zahlen ohne Nachkommastellen-3, 0, 250
floatZahlen mit Nachkommastellen1.5, -0.25, 80.0
int und float
int anzahlKreise = 4;
        float tempo = 1.5;
        float mitte = 75.0 / 2;
Kommazahlen mit Punkt: Schreibe im Programm 1.5 und nicht 1,5. Das Komma trennt in Processing die Parameter eines Befehls.
Weitere Zahlentypen: Es gibt unter anderem byte, short, long und double. Für unsere aktuellen Processing-Programme genügen meistens int und float.

3.2.2 Wahrheitswerte und einzelne Zeichen

DatentypBedeutungBeispiel
booleanWahrheitswert: wahr oder falschboolean lichtAn = true;
chargenau ein Zeichenchar taste = 'a';
boolean und char ausgeben
boolean programmLaeuft = true;
        char startTaste = 's';

        println(programmLaeuft);
        println(startTaste);

Ein char steht in einfachen Anführungszeichen. Wahrheitswerte werden im nächsten Kapitel besonders wichtig, wenn Bedingungen hinzukommen.

3.2.3 Text mit String

Ein String speichert eine Zeichenkette, also Text. Der Typ beginnt mit einem Großbuchstaben und der Text steht in doppelten Anführungszeichen.

Text speichern und verbinden
String objektName = "Ball";
        int positionX = 120;

        println(objektName + " steht bei x = " + positionX);

Das Pluszeichen verbindet hier Textstücke und Variablenwerte. Die Konsole zeigt:

Ausgabe
Ball steht bei x = 120

Das Verbinden von Zeichenketten nennt man String-Konkatenation.

3.2.4 Datentypen umwandeln

Manchmal besitzt ein Wert nicht den benötigten Datentyp. Mit int() und float() kann ein Zahlenwert gezielt umgewandelt werden.

Zahlen umwandeln
float zufallsWert = random(100); // zum Beispiel 63.84
        int ganzeZahl = int(zufallsWert); // daraus wird 63

        int anzahl = 5;
        float haelfte = float(anzahl) / 2; // ergibt 2.5

int() schneidet den Nachkommaanteil ab; es wird nicht automatisch auf die nächste ganze Zahl gerundet.

3.3

Variablenwerte verarbeiten und verändern

3.3.1 So wird eine Zuweisung verarbeitet

Bei einer Zuweisung arbeitet Processing immer in derselben Reihenfolge: Zuerst werden die Variablen auf der rechten Seite durch ihre aktuellen Werte ersetzt. Danach wird gerechnet. Erst zuletzt wird das Ergebnis links gespeichert.

Beispiel
int a = 5;
        int b = 0;

        b = a + 10;
Variablenwert einsetzen: Aus b = a + 10; wird b = 5 + 10;.
Rechnung ausführen: Aus b = 5 + 10; wird b = 15;.
Ergebnis speichern: Die Variable b erhält den neuen Wert 15.

Bei längeren Rechnungen gelten die bekannten Regeln: Klammern sowie Punktrechnung werden vor Strichrechnung verarbeitet.

3.3.2 Einen vorhandenen Wert verändern

Damit eine Variable beispielsweise um 1 wächst, muss der berechnete neue Wert wieder in derselben Variable gespeichert werden.

Wert erhöhen
int x = 10;
        x = x + 1;  // x erhält den neuen Wert 11
Keine Veränderung
x + 1; berechnet zwar einen Wert, speichert ihn aber nirgends.
Wert verändert
x = x + 1; berechnet den neuen Wert und weist ihn wieder x zu.
Kurzschreibweise: x++; erhöht x ebenfalls um 1. Für den Anfang ist x = x + 1; oft verständlicher, weil die Zuweisung sichtbar bleibt.

3.3.3 Ausführungsreihenfolge im aktiven Modus

Globale Variablen ergänzen den bekannten Ablauf aus Kapitel 2. Processing verarbeitet ein aktives Programm in dieser Reihenfolge:

1. Globale Variablenanlegen und initialisieren
→
2. setup()einmal ausführen
→
3. draw()immer wieder ausführen
Werte Schritt für Schritt verfolgen
int punktestand = 0; // zuerst: globale Initialisierung

        void setup() {
          println(punktestand); // Ausgabe: 0
          punktestand = punktestand + 1;
        }

        void draw() {
          println(punktestand); // 1, danach 101, 201, ...
          punktestand = punktestand + 100;
        }
Merke: Eine globale Initialisierung geschieht nur einmal beim Programmstart. Eine Zuweisung in draw() wird dagegen in jedem Frame erneut ausgeführt.

3.3.4 Animation mit einer Variablen

Eine Animation entsteht, wenn draw() ein Objekt zeichnet und anschließend eine seiner Eigenschaften verändert. Im nächsten Frame wird das Objekt mit dem neuen Wert gezeichnet.

Ein Ball bewegt sich nach rechts
float ballX = 0;
        float tempo = 1.5;

        void setup() {
          size(500, 300);
        }

        void draw() {
          background(235);           // altes Bild löschen
          fill(240, 100, 60);
          ellipse(ballX, 150, 50, 50);
          ballX = ballX + tempo;       // Position für den nächsten Frame
        }
ballX
speichert die aktuelle x-Koordinate des Balls.
tempo
legt fest, um wie viele Pixel sich die Position pro Frame verändert.

Die häufig benötigte Geschwindigkeit steht nur an einer Stelle. Wird tempo auf 4 gesetzt, bewegt sich der Ball schneller.

3.3.5 Variablen durch Events verändern

Ereignisfunktionen können Variablen verändern. draw() verwendet danach in allen folgenden Frames die neuen Werte.

Tastatur und Maus ändern den Hintergrund
int rot = 230;
        int gruen = 230;
        int blau = 230;

        void setup() {
          size(500, 300);
        }

        void draw() {
          background(rot, gruen, blau); // aktuelle Werte verwenden
          fill(255);
          rect(190, 100, 120, 100);
        }

        void keyPressed() {
          rot = 210; gruen = 50; blau = 50; // rot
        }

        void mousePressed() {
          rot = 45; gruen = 170; blau = 90; // grün
        }

Die Ereignisfunktionen zeichnen hier nichts. Sie verändern nur Daten. Die gesamte Darstellung bleibt in draw() und wird dort mit den jeweils aktuellen Farbwerten aufgebaut.

3.4

Globale und lokale Variablen

3.4.1 Globale Variablen

Eine globale Variable wird außerhalb von setup(), draw() und den Ereignisfunktionen deklariert – üblicherweise ganz oben im Programm. Sie kann in allen Code-Blöcken verwendet und verändert werden.

Eine Variable in mehreren Code-Blöcken
float ballX = 0; // global: überall sichtbar

        void setup() {
          size(500, 300);
        }

        void draw() {
          background(245);
          ellipse(ballX, 150, 50, 50);
          ballX = ballX + 2;
        }

        void keyPressed() {
          ballX = 0; // Ball zurücksetzen
        }

ballX muss global sein, weil draw() und keyPressed() auf denselben gespeicherten Wert zugreifen.

3.4.2 Lokale Variablen

Eine lokale Variable wird innerhalb eines Code-Blocks deklariert. Sie ist nur dort verfügbar und eignet sich für Zwischenergebnisse, die außerhalb dieses Blocks nicht benötigt werden.

Lokales Zwischenergebnis in draw()
float ballX = 20; // global

        void setup() {
          size(500, 300);
        }

        void draw() {
          background(235);
          float durchmesser = ballX / 2 + 20; // lokal
          ellipse(ballX, 150, durchmesser, durchmesser);
          ballX = ballX + 1;
        }

durchmesser wird nur für die Zeichnung in draw() benötigt. Nach jedem Durchlauf endet seine Gültigkeit; im nächsten Frame wird die lokale Variable neu angelegt und neu berechnet.

3.4.3 Skopus: Wo gilt eine Variable?

Der Skopus – englisch scope – ist der Bereich, in dem eine Variable sichtbar und verwendbar ist.

VariableDeklarationSkopus
globalaußerhalb aller Code-Blöckegesamtes Programm
lokalinnerhalb eines Code-Blocksvon der Deklaration bis zur schließenden Klammer des Blocks
Außerhalb des Skopus
void setup() {
          int startX = 50; // nur in setup() bekannt
        }

        void draw() {
          ellipse(startX, 100, 40, 40);
          // Fehler: startX ist hier unbekannt
        }

Soll startX sowohl in setup() als auch in draw() benutzt werden, muss die Variable global deklariert werden.

3.4.4 Überschatten vermeiden

Wird innerhalb eines Blocks eine neue lokale Variable mit demselben Namen wie eine globale Variable deklariert, verdeckt die lokale Variable vorübergehend die globale. Dies nennt man Überschatten.

Fehler durch Überschatten
float ballX = 0; // globale Variable

        void setup() {
          size(500, 300);
          float ballX = 100; // neue lokale Variable!
        }

        void draw() {
          ellipse(ballX, 150, 40, 40);
          // Verwendet weiterhin das globale ballX mit dem Wert 0
        }

In setup() wurde versehentlich ein zweites ballX angelegt. Die globale Variable bleibt unverändert. Richtig ist eine normale Zuweisung ohne erneuten Datentyp:

Korrektur
void setup() {
          size(500, 300);
          ballX = 100; // vorhandene globale Variable verändern
        }
Merke: Der Datentyp steht nur dort, wo eine neue Variable deklariert wird. Bei einer späteren Zuweisung wird nur der Variablenname geschrieben.
3.5

Typische Fehler

Die Variable wurde nicht deklariert

Bevor du tempo verwendest, muss eine passende Deklaration wie float tempo = 2.5; vorhanden sein.

Der Datentyp passt nicht zum Wert

int tempo = 1.5; funktioniert nicht, weil int keine Nachkommastellen speichert. Verwende float.

Eine Kommazahl wurde mit Komma geschrieben

Schreibe 1.5 statt 1,5. Das Dezimaltrennzeichen im Programmcode ist der Punkt.

Der Wert wird berechnet, aber nicht gespeichert

x + 1; verändert x nicht. Benötigt wird die Zuweisung x = x + 1;.

Eine lokale Variable wird außerhalb ihres Blocks verwendet

Prüfe die geschweiften Klammern. Eine in setup() deklarierte lokale Variable ist in draw() nicht sichtbar.

Eine globale Variable wird versehentlich überschattet

Schreibe bei einer späteren Zuweisung nicht erneut den Datentyp. ballX = 100; verändert die vorhandene Variable; float ballX = 100; legt eine neue lokale Variable an.

Groß- und Kleinschreibung wurden vertauscht

kreisX, KreisX und kreisx sind drei verschiedene Namen. Verwende einen Namen im gesamten Programm einheitlich.

Bedingungen und Entscheidungen

Mit if, else und Wahrheitswerten entscheidet dein Programm, welcher Code ausgeführt wird.

Was lernst du in diesem Kapitel?

Bisher wurden die Anweisungen in deinen Programmen meistens Zeile für Zeile ausgeführt. Nun lernt dein Programm, auf Situationen zu reagieren und zwischen verschiedenen Möglichkeiten zu entscheiden.

4.1

Einfache Bedingungen mit if und else

4.1.1 Kontrollfluss: Nicht immer läuft alles gleich ab

Normalerweise arbeitet Processing den Code von oben nach unten ab. Eine Bedingung kann diesen Kontrollfluss verändern: Ein Code-Block wird nur dann ausgeführt, wenn die geprüfte Aussage wahr ist.

Bedingung prüfenIst die Aussage wahr?
→
trueCode-Block ausführen
→
danachnormal weiterarbeiten

Ist die Bedingung false, überspringt Processing den zugehörigen Block. Anschließend läuft das Programm unterhalb der Bedingung normal weiter.

4.1.2 Aufbau einer if-Anweisung

Schlüsselwortif
Prüfung(Bedingung)
Aktion{ Code-Block }
Grundform einer if-Anweisung
if (Bedingung) {
          // Wird nur bei true ausgeführt
          Anweisung;
        }

Im nächsten Beispiel wird der Kreis rechts von der Fenstermitte orange. Links bleibt er blau.

Beispiel: Farbe abhängig von mouseX
void setup() {
          size(600, 400);
          noStroke();
        }

        void draw() {
          background(235);
          fill(40, 150, 220); // zunächst blau

          if (mouseX > width / 2) {
            fill(255, 140, 40); // rechts: orange
          }

          ellipse(mouseX, mouseY, 70, 70);
        }
Vor der Bedingung: Die Füllfarbe wird in jedem Durchlauf auf Blau gesetzt.
Bei true: Die orange Farbe ersetzt Blau, bevor der Kreis gezeichnet wird.

4.1.3 Vergleichsoperatoren

Eine Bedingung ist ein boolescher Ausdruck. Das bedeutet: Das Ergebnis ist immer entweder true oder false.

OperatorBedeutungBeispiel
>größer alsx > 100
<kleiner alsx < 100
>=größer oder gleichpunkte >= 50
<=kleiner oder gleichalter <= 18
==gleichx == 100
!=ungleichx != 100
Wichtig für Processing: Tippe die Operatoren immer mit den einzelnen Tastaturzeichen: >=, <= und !=. Die mathematischen Einzelzeichen ≥, ≤ und ≠ gehören nicht in den Quellcode.
Zuweisung oder Vergleich? x = 100; speichert einen Wert. x == 100 prüft dagegen, ob der aktuelle Wert 100 ist. Für den Gleichheitsvergleich brauchst du zwei Gleichheitszeichen.

4.1.4 Code-Blöcke und Einrückung

Die geschweiften Klammern fassen mehrere Anweisungen zu einem Code-Block zusammen. Alle Anweisungen im Block gehören zur Bedingung.

Mehrere Anweisungen im if-Block
if (mousePressed) {
          fill(255, 80, 80);
          strokeWeight(5);
          ellipse(mouseX, mouseY, 100, 100);
        }

Rücke die Zeilen im Block ein. Die Einrückung ändert zwar nicht die Bedeutung des Programms, macht aber sofort sichtbar, welche Zeilen zusammengehören. Processing kann den Code über Bearbeiten → Autoformatierung oder mit Strg+T automatisch einrücken.

Verschachtelte Bedingungen: Ein Code-Block darf eine weitere if-Anweisung enthalten. Die zweite Bedingung wird dann nur geprüft, wenn Processing den äußeren Block ausführt.

4.1.5 if–else: Zwei mögliche Wege

Mit else legst du fest, was geschehen soll, wenn die Bedingung falsch ist. Bei einer if–else-Anweisung wird immer genau einer der beiden Blöcke ausgeführt.

Links blau, rechts orange
void draw() {
          background(235);

          if (mouseX > width / 2) {
            fill(255, 140, 40); // Bedingung ist wahr
          } else {
            fill(40, 150, 220); // Bedingung ist falsch
          }

          ellipse(mouseX, mouseY, 70, 70);
        }
Zusammengehörig: Zwischen dem schließenden } des if-Blocks und else darf keine weitere Anweisung stehen.

4.1.6 Beispiel: Ein Ball erscheint wieder links

Der Ball bewegt sich nach rechts. Sobald seine Position größer als die Fensterbreite ist, wird ballX wieder auf 0 gesetzt.

Bewegung mit Rücksprung
int ballX = 0;
        int geschwindigkeit = 4;

        void setup() {
          size(600, 300);
        }

        void draw() {
          background(235);
          ellipse(ballX, height / 2, 40, 40);

          ballX = ballX + geschwindigkeit;

          if (ballX > width) {
            ballX = 0; // links neu beginnen
          }
        }
Warum nicht ballX == width? Bei einer Geschwindigkeit von 4 kann der Wert über die exakte Fensterbreite springen. > oder >= funktioniert deshalb zuverlässiger.
4.2

Mehrere Fälle mit else if

4.2.1 Mehr als zwei Möglichkeiten

Mit else if kannst du weitere Bedingungen ergänzen. Processing prüft sie von oben nach unten. Sobald eine Bedingung wahr ist, wird ihr Block ausgeführt und die restliche Kette übersprungen.

Allgemeiner Aufbau
if (Bedingung1) {
          // erster Fall
        } else if (Bedingung2) {
          // zweiter Fall
        } else {
          // alle übrigen Fälle
        }
Genau ein Weg: In einer zusammenhängenden if–else if–else-Kette wird höchstens ein Code-Block ausgeführt.

4.2.2 Die Reihenfolge der Bedingungen ist wichtig

Beginne bei gestaffelten Grenzwerten mit dem strengsten beziehungsweise größten Wert. Sonst kann ein allgemeiner Fall einen genaueren Fall abfangen.

Bewertung nach Punktzahl
int punkte = 84;

        if (punkte >= 90) {
          println("sehr gut");
        } else if (punkte >= 75) {
          println("gut");
        } else if (punkte >= 50) {
          println("bestanden");
        } else {
          println("nicht bestanden");
        }

Bei 84 Punkten ist die erste Bedingung falsch, die zweite aber wahr. Deshalb wird "gut" ausgegeben; die weiteren Bedingungen werden nicht mehr geprüft.

4.2.3 Beispiel: Drei Bildschirmbereiche

Die Mausposition entscheidet, welche Hintergrundfarbe angezeigt wird.

Linkes, mittleres und rechtes Drittel
void setup() {
          size(600, 300);
        }

        void draw() {
          if (mouseX < width / 3) {
            background(120, 190, 240); // links
          } else if (mouseX < 2 * width / 3) {
            background(120, 210, 160); // Mitte
          } else {
            background(255, 180, 90); // rechts
          }
        }
Warum genügt im zweiten Fall mouseX < 2 * width / 3? Dieser Fall wird nur geprüft, wenn das linke Drittel bereits ausgeschlossen wurde.
4.3

Boolesche Ausdrücke verknüpfen

4.3.1 Logisches UND: &&

Ein logisches UND ist nur dann wahr, wenn beide Teilaussagen wahr sind. In Processing schreibst du dafür &&.

ABA && B
truetruetrue
truefalsefalse
falsetruefalse
falsefalsefalse
Ein Wert liegt zwischen zwei Grenzen
int x = 150;

        if (x > 100 && x < 300) {
          println("x liegt im Bereich");
        }
Nicht wie in Mathematik schreiben: 100 < x < 300 ist in Processing keine geeignete Bereichsprüfung. Formuliere zwei Vergleiche und verbinde sie mit &&.

4.3.2 Logisches ODER: ||

Ein logisches ODER ist wahr, sobald mindestens eine Teilaussage wahr ist. Das Zeichen | erreichst du unter Windows meist mit Alt Gr + <.

ABA || B

falsetruetrue

Außerhalb des Fensters
if (ballX < 0 || ballX > width) {
          println("Der Ball ist außerhalb.");
        }

4.3.3 Logisches NICHT: !

Das Ausrufezeichen kehrt einen Wahrheitswert um: Aus true wird false und aus false wird true.

A!A
truefalse
falsetrue
Beispiel: nicht pausiert

          println("Die Animation läuft.");
        }

4.3.4 Klammern und Priorität

Processing wertet zuerst !, dann && und zuletzt || aus. Setze bei gemischten Ausdrücken trotzdem Klammern. Dadurch wird deine Absicht deutlich und Fehler lassen sich leichter vermeiden.

Lesbar geklammerte Bedingung
if ((punkte >= 50 && anwesend) || sonderregel) {
          println("Bedingung erfüllt");
        }
Normalfall: Mindestens 50 Punkte und Anwesenheit sind erforderlich.
Alternative: Eine aktive Sonderregel reicht ebenfalls aus.

4.3.5 Beispiel: Ein Ball prallt an beiden Rändern ab

Am linken oder rechten Rand soll die Bewegungsrichtung wechseln. Beide Fälle führen dieselbe Anweisung aus und können deshalb mit ODER verbunden werden.

Richtungswechsel am Fensterrand
int ballX = 100;
        int geschwindigkeit = 4;

        void setup() {
          size(600, 300);
        }

        void draw() {
          background(235);
          ellipse(ballX, height / 2, 40, 40);

          ballX = ballX + geschwindigkeit;

          if (ballX < 0 || ballX > width) {
            geschwindigkeit = -geschwindigkeit; // Richtung umkehren
          }
        }
Vorzeichen umkehren: Aus 4 wird −4, beim nächsten Randkontakt wieder 4. Dadurch bewegt sich der Ball abwechselnd nach rechts und links.
4.4

Boolesche Variablen

4.4.1 true und false speichern

Eine Variable vom Datentyp boolean kann genau zwei Werte speichern: true oder false. Sie eignet sich besonders für Zustände mit zwei Möglichkeiten.

ZustandMögliche Variable
Animation läuft oder pausiertboolean laeuft = true;
Objekt sichtbar oder unsichtbarboolean sichtbar = true;
Licht an oder ausboolean lichtAn = false;

4.4.2 Eine boolesche Variable direkt als Bedingung

Eine boolesche Variable ist bereits eine vollständige Bedingung. Du musst sie nicht noch mit true vergleichen.

Play und Pause
int ballX = 0;
        boolean laeuft = true;

        void draw() {
          background(235);
          ellipse(ballX, 100, 40, 40);

          if (laeuft) {
            ballX = ballX + 3;
          }
        }
Kürzer und klarer: Schreibe if (laeuft) statt if (laeuft == true).

4.4.3 Einen Zustand umschalten

Mit dem NICHT-Operator kannst du einen Zustand bei jedem Tastendruck umkehren. Diese Technik nennt man auch Toggle.

Zwischen Play und Pause wechseln
void keyPressed() {
          laeuft = !laeuft; // true wird false und umgekehrt
        }
laeuft enthält zunächst beispielsweise true.
!laeuft ergibt dann false.
Das Ergebnis wird wieder in laeuft gespeichert.

4.4.4 Das Ergebnis eines Ausdrucks speichern

Auch das Ergebnis eines Vergleichs oder einer Verknüpfung kann in einer booleschen Variablen gespeichert werden.

Bereichsergebnis merken
int ballX = 180;
        boolean imBereich = false;

        imBereich = ballX > 100 && ballX < 300;

        if (imBereich) {
          println("Der Ball liegt im markierten Bereich.");
        }

Die Variable macht eine längere Bedingung lesbarer und erlaubt es, das Ergebnis später an einer anderen Stelle erneut zu verwenden.

4.5

Tastatur- und Maustasten unterscheiden

4.5.1 Einmalige oder kontinuierliche Reaktion

Für Tastatur und Maus gibt es jeweils zwei unterschiedliche Möglichkeiten. Entscheidend ist, ob eine Aktion einmal beim Drücken oder dauerhaft während des Gedrückthaltens stattfinden soll.

Gewünschte ReaktionTastaturMaus
einmal beim DrückenkeyPressed()mousePressed()
solange gedrücktkeyPressed in draw()mousePressed in draw()
Klammern beachten: keyPressed() ist eine Ereignisfunktion. keyPressed ohne Klammern ist eine boolesche Systemvariable. Dasselbe gilt für mousePressed() und mousePressed.

4.5.2 Buchstaben und andere Zeichen mit key

Die Systemvariable key enthält die zuletzt gedrückte Zeichentaste. Ein einzelnes Zeichen hat den Datentyp char und steht in einfachen Anführungszeichen.

Auf a und d reagieren
int x = 300;

        void draw() {
          background(235);
          ellipse(x, 150, 40, 40);

          if (keyPressed) {
            if (key == 'a') {
              x = x - 3; // nach links
            }
            if (key == 'd') {
              x = x + 3; // nach rechts
            }
          }
        }
Groß- und Kleinschreibung: 'a' und 'A' sind zwei verschiedene Zeichen.

4.5.3 Pfeiltasten mit keyCode

Pfeiltasten erzeugen kein normales Schriftzeichen. Deshalb vergleichst du die Systemvariable keyCode mit Konstanten wie LEFT, RIGHT, UP oder DOWN.

Flüssige Steuerung mit Pfeiltasten
int x = 300;

        void setup() {
          size(600, 300);
        }

        void draw() {
          background(235);
          ellipse(x, 150, 40, 40);

          if (keyPressed && key == CODED) {
            if (keyCode == LEFT) {
              x = x - 3;
            } else if (keyCode == RIGHT) {
              x = x + 3;
            }
          }
        }

Weil die Abfrage in draw() steht, bewegt sich der Kreis flüssig, solange eine Pfeiltaste gehalten wird.

4.5.4 Maustasten mit mouseButton

Innerhalb von mousePressed() kannst du mit mouseButton zwischen linker, rechter und mittlerer Maustaste unterscheiden.

Farbe mit Maustasten wählen
int rot = 40;
        int gruen = 150;
        int blau = 220;

        void draw() {
          background(235);
          fill(rot, gruen, blau);
          ellipse(width / 2, height / 2, 100, 100);
        }

        void mousePressed() {
          if (mouseButton == LEFT) {
            rot = 40; gruen = 150; blau = 220;
          } else if (mouseButton == RIGHT) {
            rot = 255; gruen = 140; blau = 40;
          }
        }
Mögliche Werte: Für mouseButton stehen die Konstanten LEFT, RIGHT und CENTER zur Verfügung.
Hinweis: Auf einem Touchpad oder Tablet steht nicht immer eine rechte oder mittlere Maustaste zur Verfügung. Die linke Maustaste beziehungsweise ein normaler Klick funktioniert am zuverlässigsten.
4.6

Typische Fehler

Ein Gleichheitszeichen statt zwei

x = 100 ist eine Zuweisung. Eine Gleichheitsprüfung wird mit x == 100 geschrieben.

Semikolon direkt hinter der Bedingung

Schreibe nicht if (x > 100);. Das Semikolon beendet die Anweisung zu früh; der folgende Block gehört dann nicht wie beabsichtigt zum if.

Geschweifte Klammern fehlen oder stehen falsch

Markiere jeden Code-Block mit { und } und lasse den Code automatisch formatieren. So werden falsche Verschachtelungen sichtbar.

else if in ungünstiger Reihenfolge

Prüfe genaue oder hohe Grenzwerte zuerst. Eine früh erfüllte Bedingung verhindert, dass spätere Bedingungen noch geprüft werden.

UND und ODER verwechselt

&& verlangt zwei wahre Teilaussagen. Bei || reicht eine wahre Teilaussage.

keyPressed() und keyPressed verwechselt

Mit Klammern ist es eine Ereignisfunktion. Ohne Klammern ist es ein Wahrheitswert, der während des Gedrückthaltens abgefragt werden kann.

Falsche Anführungszeichen bei key

key enthält ein einzelnes Zeichen. Deshalb vergleichst du mit 'a' und nicht mit "a".

Eine exakte Position wird nie erreicht

Bei größeren Bewegungsschritten kann ein Wert über eine Grenze springen. Verwende am Rand meist >, >=, < oder <= statt ==.

NICHT! kehrt einen Wahrheitswert um.
