1.1

Grundformen zeichnen

Pixel, Koordinaten, Befehle und Zeichenreihenfolge

1.1.1 Der Bildschirm besteht aus Pixeln

Ein digitales Bild setzt sich aus vielen kleinen Bildpunkten zusammen. Diese Bildpunkte heißen Pixel. Damit Processing jeden Ort im Zeichenfenster eindeutig findet, besitzt jeder Punkt zwei Koordinaten:

  • x beschreibt die Position von links nach rechts.
  • y beschreibt die Position von oben nach unten.
Das Koordinatensystem in Processing

Anders als im Mathematikunterricht liegt der Ursprung links oben. Die y-Werte werden nach unten größer.

!

Bei 600 × 400 Pixeln: Die sichtbaren x-Positionen reichen von 0 bis 599, die y-Positionen von 0 bis 399. Die Zählung beginnt bei 0.

1.1.2 Anweisungen und Programme

Eine Anweisung ist ein präziser Befehl an den Computer. Ein Programm ist eine geordnete Folge solcher Anweisungen. Processing arbeitet den Code von oben nach unten ab.

Aufbau einer Anweisung
point(120, 80);
point

Name des Befehls: Processing soll einen Punkt zeichnen.

(120, 80)

Parameter: Sie legen die x- und y-Position des Punktes fest.

;

Semikolon: Es beendet die Anweisung.

1.1.3 Die wichtigsten Grundformen

Punkt

point(x, y);

Ein einzelner Punkt an der Position (x, y).

Linie

line(x1, y1, x2, y2);

Verbindet einen Startpunkt mit einem Endpunkt.

Dreieck

triangle(x1, y1, x2, y2, x3, y3);

Die drei Punktpaare bestimmen die drei Ecken.

Rechteck

rect(x, y, breite, hoehe);

Normalerweise: linke obere Ecke, dann Breite und Höhe.

Kreis

circle(x, y, durchmesser);

Mittelpunkt und Durchmesser bestimmen den Kreis.

Ellipse

ellipse(x, y, breite, hoehe);

Mittelpunkt, waagerechter und senkrechter Durchmesser.

Beispiel: mehrere Grundformen
size(500, 300);
background(245);

point(40, 40);
line(70, 40, 190, 90);
triangle(230, 100, 300, 100, 265, 35);
rect(50, 150, 130, 80);
circle(270, 190, 90);
ellipse(410, 190, 120, 70);

1.1.4 Die Zeichenreihenfolge entscheidet

Processing zeichnet wie auf Papier: Was später gezeichnet wird, liegt weiter vorn und kann frühere Formen verdecken.

Beispiel: Haus aus Grundformen
size(360, 300);
background(235);

// Zuerst der Hauskörper
rect(90, 120, 180, 130);

// Das Dach wird danach davor gezeichnet
triangle(70, 120, 290, 120, 180, 40);

// Tür und Fenster liegen ganz vorn
rect(155, 180, 50, 70);
rect(110, 150, 30, 30);
rect(220, 150, 30, 30);
M

Merksatz: Processing arbeitet von oben nach unten. Die zuletzt gezeichnete Form liegt ganz vorn.

1.2

Weitere Formen

Ellipsensegmente und frei zusammengesetzte Vielecke

1.2.1 Teile einer Ellipse mit arc()

Mit arc() wird nur ein Ausschnitt einer Ellipse gezeichnet. Zu Mittelpunkt, Breite und Höhe kommen ein Start- und ein Endwinkel hinzu.

Allgemeiner Aufbau

arc(x, y, breite, hoehe, startwinkel, endwinkel);

Der Winkel 0° zeigt vom Mittelpunkt nach rechts. Wegen der nach unten laufenden y-Achse werden die Winkel auf dem Bildschirm im Uhrzeigersinn sichtbar.

Winkel bei arc()

Gezeigt ist ein Bogen von 30° bis 330°. Start- und Endpunkt sind rot markiert.

Processing rechnet intern mit dem Bogenmaß. Für den Einstieg ist radians() besonders lesbar: Die Funktion wandelt Grad in Bogenmaß um.

Beispiel: Ellipsensegment
size(300, 220);
background(245);

arc(150, 110, 180, 120,
    radians(30), radians(330));

Alternativ entspricht ein Vollkreis 2 * PI. So lässt sich 30° auch als PI / 6 angeben.

1.2.2 Beliebige Vielecke mit beginShape()

Ein Polygon ist ein Vieleck. Processing verbindet dazu mehrere selbst festgelegte Eckpunkte. Jeder Eckpunkt wird mit vertex(x, y) angegeben.

Beispiel: ein unregelmäßiges Fünfeck
size(320, 260);
background(245);

beginShape();
vertex(160, 30);  // 1. Ecke
vertex(270, 100); // 2. Ecke
vertex(225, 220); // 3. Ecke
vertex(85, 210);  // 4. Ecke
vertex(45, 90);   // 5. Ecke
endShape(CLOSE);
BefehlAufgabe
beginShape();Startet die Beschreibung einer neuen Form.
vertex(x, y);Fügt einen Eckpunkt hinzu. Die Reihenfolge bestimmt die Verbindungslinien.
endShape(CLOSE);Beendet und schließt die Form: Der letzte Punkt wird mit dem ersten verbunden.
endShape();Beendet die Form, ohne die letzte Verbindung automatisch zu zeichnen.
M

Merksatz: beginShape() öffnet die Form, vertex() setzt ihre Ecken und endShape(CLOSE) schließt sie.

1.3

Kontur, Füllung und Farben

Graustufen, RGB-Farben und Transparenz

1.3.1 Graustufen von 0 bis 255

Eine einzelne Zahl beschreibt eine Graustufe. 0 bedeutet schwarz, 255 bedeutet weiß. Werte dazwischen ergeben verschiedene Grautöne. Als Merkhilfe kannst du dir die Zahl als Lichtmenge vorstellen.

Graustufen

1.3.2 Füllung und Kontur

fill() legt die Farbe im Inneren einer Form fest. stroke() legt die Konturfarbe fest, strokeWeight() ihre Dicke in Pixeln.

fill(80);

Die folgenden Flächen werden dunkelgrau gefüllt.

stroke(255);

Die folgenden Konturen werden weiß.

strokeWeight(5);

Die folgenden Konturen werden 5 Pixel dick.

noFill();

Die folgenden Formen erhalten keine Füllung.

noStroke();

Die folgenden Formen erhalten keine Kontur.

!

Die Gestaltung bleibt aktiv: Ein Farbbefehl gilt für alle Formen, die danach gezeichnet werden – bis ein neuer Farbbefehl ihn ersetzt.

Beispiel: Stile nacheinander verändern
size(520, 220);
background(235);

fill(60);          // dunkelgraue Füllung
stroke(255);       // weiße Kontur
strokeWeight(5);
circle(100, 110, 120);

noStroke();        // Kontur ab jetzt aus
fill(150);
rect(210, 50, 110, 120);

noFill();          // Füllung ab jetzt aus
stroke(0);         // Kontur wieder an
strokeWeight(3);
triangle(385, 170, 465, 170, 425, 45);

1.3.3 Größe und Hintergrund des Zeichenfensters

size(breite, hoehe) bestimmt die Größe des Fensters. background() füllt das gesamte Fenster mit einer Farbe und übermalt dabei alles, was bereits zu sehen war.

Die ersten Zeilen eines einfachen Programms
size(600, 400);  // 600 Pixel breit, 400 Pixel hoch
background(245); // fast weißer Hintergrund

circle(300, 200, 140);
×

background() nicht ans Ende setzen: Dann wird die gesamte vorherige Zeichnung übermalt. In einfachen Programmen steht der Hintergrund vor den Formen.

1.3.4 RGB-Farben

Farben entstehen aus drei Anteilen: Rot, Grün und Blau. Jeder Anteil kann einen Wert von 0 bis 255 besitzen. Die Reihenfolge ist immer R – G – B.

255, 0, 0
0, 255, 0
0, 0, 255
128, 60, 210
BefehlWirkung
fill(255, 0, 0);rote Füllung
stroke(0, 0, 255);blaue Kontur
background(240, 245, 255);sehr heller, leicht blauer Hintergrund
fill(255, 255, 0);Gelb durch Rot + Grün

1.3.5 Transparenz mit dem Alpha-Wert

Ein zusätzlicher Wert steuert die Deckkraft. Dieser Alpha-Wert reicht ebenfalls von 0 bis 255:

  • 255: vollständig deckend
  • 0: vollständig durchsichtig
  • Werte dazwischen: teilweise transparent
Beispiel: überlagerte, transparente Kreise
size(420, 260);
background(245);
noStroke();

fill(255, 0, 0, 150);  // Rot + Alpha
circle(160, 130, 150);

fill(0, 90, 255, 150); // Blau + Alpha
circle(255, 130, 150);

Bei einer Graustufe besteht die Kurzform aus zwei Werten: fill(grauwert, alpha). Bei einer RGB-Farbe sind es vier Werte: fill(rot, gruen, blau, alpha).

1.3.6 Ein vollständiges Farb-Beispiel

Beispiel: farbige Landschaft
size(600, 360);
background(180, 225, 255); // Himmel

noStroke();
fill(255, 205, 55);       // Sonne
circle(500, 80, 90);

fill(65, 155, 90);        // Wiese
rect(0, 240, 600, 120);

fill(215, 80, 65);        // Haus
rect(180, 170, 170, 120);

fill(70, 75, 95);         // Dach
triangle(155, 170, 375, 170, 265, 85);

stroke(255);                   // Fenster
strokeWeight(4);
fill(120, 210, 245);
rect(215, 205, 45, 45);
M

Merksatz: Erst Stil festlegen, dann Form zeichnen. fill(), stroke() und strokeWeight() wirken immer auf die danach folgenden Formen.

1.4 Typische Fehler - schnell erkannt

Die Form sitzt zu tief.

Der y-Wert wächst nach unten, nicht nach oben.

Processing meldet einen Syntaxfehler.

Prüfe Semikolon, Klammern, Kommata und die Schreibweise des Befehls.

Breite und Position wirken vertauscht.

Vergleiche Anzahl und Reihenfolge der Parameter mit der Befehlstabelle.

Alle Formen haben dieselbe Farbe.

Ein fill()-Befehl bleibt aktiv, bis ein neuer folgt.

Die Zeichnung ist verschwunden.

Ein später background()-Befehl hat sie wahrscheinlich übermalt.

Das Vieleck ist offen.

Verwende endShape(CLOSE), wenn letzter und erster Punkt verbunden werden sollen.

Ein Teil liegt hinter einer anderen Form.

Ändere die Reihenfolge der Zeichenbefehle.

1.5 Das Wichtigste auf einen Blick

  • Der Ursprung (0, 0) liegt links oben.
  • x wächst nach rechts, y wächst nach unten.
  • Parameter stehen in Klammern und werden durch Kommata getrennt.
  • Ein Semikolon beendet eine Anweisung.
  • Später gezeichnete Formen liegen weiter vorn.
  • arc() zeichnet einen Teil einer Ellipse.
  • Vielecke entstehen mit beginShape(), vertex() und endShape().
  • Graustufen reichen von 0 bis 255.
  • RGB-Farben bestehen aus Rot, Grün und Blau.
  • Der Alpha-Wert steuert die Deckkraft.
  • Gestaltungsbefehle gelten für alle nachfolgenden Formen.
